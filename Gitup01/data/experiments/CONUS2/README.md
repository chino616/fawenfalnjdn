# CONUS2

Independent CONUS2 experiment skeleton.

This directory is intentionally separate from the existing CONUS implementation:

- `data/experiments/conus_plus_ge73_pheno`
- `src/cevns_pyeft/experiments/conus`

No physics model, detector response, measured spectrum, Slow counts, Fast
counts, or statistics implementation is defined here yet.

Before CONUS2 is implemented, the source paper or data release must be selected
and the experiment identity, target, exposure, binning, detector response, and
statistical data semantics must be approved.
