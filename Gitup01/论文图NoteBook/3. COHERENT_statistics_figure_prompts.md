## 2. 从源码得到的具体判断

### 2.1 数据、单位、统计函数

| 模块 | 已确认内容 | 对绘图的影响 |
|---|---|---|
| `statistics/datasets.py` | `csi2021_dataset()` 返回 9 个 PE 箱；数据、背景、误差单位都是 `counts/PE` | 必须将原始 `events/bin` 预测除以各自箱宽，不能直接叠加 |
| 同上 | CsI2021 最后一个数据值为负；数据定义为 residual | 负值不是程序错误；不能把该数组当作 Poisson 原始计数 |
| `statistics/observables.py` | `convert_prediction_to_dataset_observable()` 负责单位与箱边界一致性 | 所有似然和数据叠图统一走该接口 |
| `statistics/likelihoods.py` | `chi2_csi2021()` 调用 Gaussian 双 nuisance 解析 profile | 当前没有完整能量—时间 Poisson 似然 |
| `statistics/profiling.py` | `ProfileResult` 包含 `chi2, alpha, beta, chi2_data, chi2_nuisance, success` | 保存这些值，可画 nuisance pull 和拟合残差 |
| `statistics/datasets.py` | CsI2021 的信号/背景相对误差为 0.125/0.35 | 两者是当前 legacy 模型的约定，不等于完整官方系统误差模型 |
| `statistics/likelihoods.py` | Ar 提供 `chi2_ar2020_irls()` 与 `chi2_ar2020_bounded()` | 两种算法不能无说明混用；必要时在极小值、边界点比较 |
| `data/experiments/*/statistics/provenance.yaml` | CsI2021、Ar2020 均明确为 legacy approximate statistics，缺少权威输入溯源 | 当前结果可以作为程序分析示例；不能称为 official/full COHERENT likelihood |

CsI2021 的当前定义是

\[
\chi^2(C,\alpha,\beta)
=\sum_i\frac{[D_i-(1+\alpha)S_i(C)-(1+\beta)B_i]^2}{\sigma_i^2}
+\frac{\alpha^2}{0.125^2}+\frac{\beta^2}{0.35^2}.
\]

这里 `S_i` 是转换后的 `counts/PE`；原始事件总数应从 `events/bin` 求和，或对 `counts/PE` 乘箱宽后求和。

### 2.2 味参数与预测链

真实接口：

```python
from cevns_pyeft.statistics.parameters import (
    VectorNSIParameters, vector_nsi_to_np_wilson,
)
from cevns_pyeft.statistics.predictors import predict_raw_components
from cevns_pyeft.statistics.datasets import csi2021_dataset
from cevns_pyeft.statistics.observables import convert_prediction_to_dataset_observable
from cevns_pyeft.statistics.likelihoods import chi2_csi2021

params = VectorNSIParameters(epsilon_ee_uV=0.05)
wc_np = vector_nsi_to_np_wilson(params)
prediction = predict_raw_components(
    "CsI2021", wc_np,
    mode="fast",
    fast_kernel_path="tests/reference_CsI2021/fast_kernel.npz",
    include_sm=True,
)
dataset = csi2021_dataset()
signal = convert_prediction_to_dataset_observable(prediction.total, dataset.observable)
fit = chi2_csi2021(signal, dataset)
```

这段公共 API 路径已在本次核查中实际运行。

`vector_nsi_to_np_wilson()` 的约定为

\[
\hat C^{(6),\mathrm{NP}}_{1q}=-\sqrt{2}G_F\epsilon^{qV},\qquad q=u,d.
\]

它返回 `(6,1,"u")`、`(6,1,"d")` 两个 **NP-only** 的 `3×3` 矩阵。非对角元自动填充其厄米共轭。必须由预测层 `include_sm=True` 加入 SM 一次；不得在参数层再手工加入 SM。

| 开启参数，其他参数为零 | 应改变的 SNS 源成分 |
|---|---|
| `epsilon_ee_uV` 或 `dV` | `e` |
| `epsilon_mumu_uV` 或 `dV` | `mu`、`mub` |
| 实数 `epsilon_emu_uV` 或 `dV` | `e`、`mu`、`mub` |
| `epsilon_etau_uV` 或 `dV` | `e` |
| `epsilon_mutau_uV` 或 `dV` | `mu`、`mub` |
| 仅 `epsilon_tautau_uV` 或 `dV` | 当前未传播的 SNS 源中均不变 |

最后一行是当前源模型的零敏感度检查。不能由此说 COHERENT 不敏感于任何含 tau 的耦合；`e-tau` 和 `mu-tau` 仍可产生不可观测末态味的散射。

`experiments/coherent/sns.py` 的 `sns_component_state()` 明确说明，当前反中微子标签尚未完成独立的 interaction-kernel 审计。本次图组聚焦已检查的矢量 NSI；不能据此扩展成所有 EFT 算符的中微子/反中微子符号都已验证。

### 2.3 现有三个结果脚本，分别能做什么

| 脚本 | 实际行为 | 论文任务中的处理 |
|---|---|---|
| `tools/statistics/run_coherent_flavor_results.py` | 味成分检查、10 个一维参数、3 个二维平面；一维固定 `[-0.3,0.3]`/61 点；二维固定 `[-0.35,0.35]`/41 点；成分谱默认用粗 slow 网格 | 可复用逻辑，不能把默认输出直接当最终论文扫描 |
| `tools/statistics/run_coherent_ar_combined_results.py` | CsI2021+Ar2020 的 `ee u/d`、`mumu u/d` 图；Ar 核默认 `3×8×3`；NPZ 只保存各自和联合的 `Δχ²` | 更换为经验证的核；保存 raw profiled `χ²`；明确独立 nuisance 的近似 |
| `tools/statistics/run_coherent_flavor_highres_all.py` | 101×101 等参数网格；`ee u/d`、`mumu u/d`、`emu u/d`；`DATASET_ORDER` 包含 CsI2021、CsI2017、Ar2020，并全部相加 | 不直接使用其 combined 作论文约束；两代 CsI 数据不能默认独立 |

代码还存在以下会影响作图解释的细节：

1. `scan_grid_1d/2d()` 只减去网格上的最小值，没有自动连续最小化，也没有自动扩大范围。
2. `confidence.py` 已有 `refine_global_minimum()` 与 `extract_intervals()`，但主结果脚本的一维扫描没有用它们完成最终区间提取。
3. `extract_intervals(..., root_func=...)` 的 `root_func` 应返回 `chi2_profile(x)-chi2_min-threshold`，不是原始 `χ²`。
4. highres 脚本所谓 `integration_convergence_checks`，对 CsI 主要读取既有 fast/slow 元数据；这不是独立的积分网格细化研究。
5. highres 的 `PASS` 主要依据 fast/slow 标记与图文件数量；轮廓触碰边界被记录，但不必然令总状态失败。`PASS` 不代表论文结果已验证。
6. highres 的缓存复用主要检查文件存在，未严格绑定核、源码、似然和参数配置；正式作图需增加配置指纹，避免读入旧结果。
7. `predict_raw_components(mode="fast")` 每次经过 `reconstruct_saved_kernel()`，后者重新读核。大扫描建议在新绘图脚本中将核加载一次，保持数值与公共 API 一致。

## 5. 暂缓或另立任务的内容

### 5.1 能量—时间分析

这是可提高论文内容的扩展，但需要新增输入与 likelihood。现有 `DEFAULT_ACCEPTANCE={e:0.848,mu:0.997,mub:0.848}` 是每种源成分的整体接受度，不提供可直接使用的时间箱。

若后续实施，应核查官方数据发布中的 on/off 计数、二维 binning、BRN/NIN/稳态背景、束流时间分布、时间效率及 nuisance。arXiv:2110.07730 的 ancillary files 列出了 `dataBeamOnC.txt`、`dataBeamOnAC.txt`、`brnTrec.txt`、`ninTrec.txt`、`snsFlux2D.root` 等，可作为输入调查起点，不能只根据文件名推断数组形状或归一化。

必须避免在显式时间积分中重复乘入现有整体 time acceptance。对照文献的 9×11 分箱必须从数据与文献核实，而非把 9 个能谱箱随意拆成 11 份。

实现后再做“仅能谱 vs 能谱+时间”的 S3 扩展。新增实验统计数据或 likelihood 时，遵循本地 AGENTS.md 对 experiment-integration workflow 的适用要求；本文的普通绘图任务不自动触发全部迁移阶段。

### 5.2 完整 EFT 能标总览

程序的核具有 22 个算符结构，但当前结果脚本的参数入口专门针对 dimension-six vector NSI。迁移报告也将部分完整 scalar-operator scan/CLI 留为 deferred。

因此不要把 `epsilon` 扫描改个横轴就作为全部 d=5,6,7,8 能标图。若单独实施，应直接扫描相应 NP Wilson 矩阵，验证该算符的匹配、单位、干涉与反中微子处理，并对符号分支分别记录。

在声明 `|C_dimensionless|=1` 的约定下，可以使用 `Lambda=|C_dimensionful|^(-1/(d-4))` 转换。必须先处理多分支允许集合；一个简单的统一下限可能隐藏有限 Lambda 的允许岛。此图属于独立完成并验证后的附加结果。

### 5.3 文献曲线复现

没有文献 raw profiled χ² 数组时，允许：

- 运行 native 模型并说明假设；
- 在明确来源和提取误差后对文献图片做数字化比较；
- 输出待核对输入清单。

不允许：把现有 native NPZ 改名为 paper-matched；手工移动轮廓对齐文献；把文献图的示意形状作为程序计算结果；用矢量 NSI 替代 scalar/tensor。
