# CONUS Legacy Normalization Forensic Audit

## Objective

Perform a forensic audit of the legacy CONUS Mathematica normalization and
observable conventions.

The immediate goal is NOT to modify production physics code.

The goal is to determine which of the following is actually wrong:

1. the numerical CEvNS prediction;
2. the meaning of the legacy parameter `119`;
3. the physical unit assigned to `binCounts`;
4. the physical unit assigned to `yData`;
5. the Mathematica plot-axis label;
6. the later PDF/document interpretation of the legacy code;
7. the current Python dataset contract.

The audit must resolve these ambiguities as far as the available evidence
allows and produce a user-readable correction report.

# 2. Main hypothesis to test

The current leading hypothesis is:

```text
Legacy yData is numerically an absolute-events-per-bin quantity,
while the old Mathematica plot axis label

Counts [kg^-1 (10 eVee)^-1]

is incorrect or inherited from an earlier rate-normalized version.
```

A second possibility is:

```text
119 originally represented reactor-on live time in days,
and some later code/document layer changed its semantics to kg day.
```

A third possibility is:

```text
the legacy code mixes a rate-like plotted observable with an
absolute-event normalization in a way that was never dimensionally closed.
```

Do not assume any hypothesis is correct before tracing the code and provenance.
