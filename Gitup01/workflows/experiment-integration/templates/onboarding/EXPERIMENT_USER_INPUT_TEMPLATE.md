# CEvNS 实验迁移：用户输入模板

本表用于**一个独立的数据集或运行配置**。若运行期、探测器配置、源、靶材或统计数据定义不同，请复制本表分别填写。它是资料接收表，不是程序的 `experiment.yaml`，也不是要求用户编写物理推导或 Python 代码。

参考：[CsI2021 按本表填写的示例](EXPERIMENT_USER_INPUT_CsI2021_EXAMPLE.md)；[P01–P10 阶段填写模板](../phase/P01_P10_PHASE_TEMPLATES.md)；[从 CsI2021 提炼的核心函数结构](../phase/CsI2021_CORE_FUNCTION_STRUCTURE.md)。用户用本表提供资料，AI 用阶段模板记录函数映射、复用判断和 Gate；CsI 数值不是其他实验的默认值。

## 两种使用方式

1. **自己填写**：复制本表，按本次计算目标填写相关栏目；可以写数值、公式，
   也可以只给论文页码、表号、文件路径或链接。每个数值请写单位。
2. **提供材料，由 AI 总结**：提供论文、补充材料、官方数据或旧程序的位置/文件。
   AI 会按本表逐项摘录和预填，附来源位置，再请你核对缺失、冲突以及需要选择的物理定义。
   已能从材料找到的信息不必重复填写。

两种方式可混合使用。找不到时写“缺失”，确实不用时写“不适用”，不要用 `0`
代替缺失。AI 的预填是待核对摘要，不表示已获批准的实验定义。

## 必填范围速览

| 希望得到的结果 | 必须明确的输入 |
| --- | --- |
| 真实核反冲谱 | 第 1–4 节：数据集、源、靶与曝光、截面与运动学 |
| 重建谱或逐箱信号事例数 | 第 1–6 节：再加探测器响应、效率和分箱 |
| likelihood、χ² 或置信区间 | 第 1–7 节：再加观测数据及统计定义 |
| 与论文或旧程序数值等价的声明 | 相应计算输入，再加第 8 节的外部基准及其运行条件 |
| Fast 计算 | 先有已验证的 Slow；第 9 节只说明加速目标和适用参数范围 |

## 1. 实验身份、资料与目标【所有迁移必填】

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 实验名称、运行期和唯一数据集名称 | 待填 |
| 本表覆盖的探测器或运行配置 | 待填 |
| 主要论文、补充材料、官方数据文件 | 待填；请给 DOI/arXiv/链接/本地路径及版本 |
| 可选的旧程序或参考数组 | 待填或“不适用”；旧程序应标为参考，不自动成为实验物理定义 |
| 本次科学目标 | 真实反冲谱 / 重建谱 / 逐箱信号 / Fast / 统计；写出所需项目 |
| 结果性质 | 官方数值复现 / 明确的近似模型 / 旧程序回归 / 新预测；写明范围 |

> 如果论文包含多个独立运行期或不同探测器配置，请在这里列出来，执行者负责判断是否拆成多个数据集。

## 2. 输出量与数据轴【所有迁移必填】

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 真实核反冲量和单位 | 例如核反冲能量 (T)，单位待填 |
| 最终观测量和单位 | 例如重建电离能、光电子数；只算真实反冲谱时填“不适用” |
| 希望保留的分量轴 | 例如探测器、靶同位素、源分量、时间、能量箱；没有就填“只需总量” |
| 输出是计数还是率 | 例如 `events/bin`、`events/kg/day/keV`；不能只写“谱” |
| 精确 bin edges | 提供边界表、论文表号，或最小值、最大值、宽度和端点规则；不做分箱时填“不适用” |

## 3. 中微子源【任何信号预测必填】

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 入射粒子、flavor 或 flavor 状态 | 中微子/反中微子；单一 flavor、混合态或能量依赖密度矩阵 |
| 需要分别输出的源分量 | 写出分量名称；若只要求总谱，填“总通量即可” |
| 能谱公式或数值表 | 给公式出处、表格文件或现有函数；注明它是源发射谱还是探测器位置通量 |
| 能量范围及单位 | 最小/最大能量，表格能量单位 |
| 谱值单位与时间基准 | 例如每次裂变每 MeV、`cm^-2 s^-1 MeV^-1` 或已对运行期积分的 fluence |
| 数值表处理规则 | 插值、分段拼接、范围外取值；只有解析公式时填“不适用” |

**绝对归一化只选一条路径：**

- [ ] **A. 已给探测器位置的绝对通量/积分注量。** 数值或文件：____；单位：____；是否已包含运行时间：____。
- [ ] **B. 从源发射量推导探测器通量。** 源强或功率：____；分量权重和产额：____；距离/几何：____；运行时间处理：____。

若资料同时给出 A、B，请标明哪条是计算定义、哪条仅用于交叉检查，避免重复归一化。

## 4. 靶材、曝光、截面与运动学【任何信号预测必填】

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 靶材料和同位素组成 | 单一同位素、天然混合物或化合物；给同位素丰度/化学计量及其来源 |
| 靶核质量或摩尔质量来源 | 论文、数据表或项目默认来源；执行者负责计算每单位质量的核数 |
| 每台探测器的质量与活时间 **或** 已给出的曝光 | 给数值/文件及单位；明确曝光是否已经等于质量 × 活时间 |
| 散射模型和参数点 | 例如现有项目 SM；若为 EFT，给系数基底、取值和 flavor 约定 |
| 核 form factor/Response 的要求 | 使用论文指定模型、现有项目模型或提供新的核响应资料；注明同位素对应关系 |
| 运动学和截面约定 | 弹性散射或指定近似；入射能量、反冲能量、`dσ/dT` 的单位；若论文有特殊积分边界请给出处 |

> 如果源给的是已按时间积分的 fluence，曝光中的时间不能再乘一次。若项目已有满足要求的截面实现，用户只需说明物理模型和参数点，无需填写函数名或重写公式。

## 5. 探测器响应【要求重建谱或逐箱计数时必填】

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 真实反冲到观测量的平均映射 | quenching、yield、能量刻度等公式/曲线与参数；若理想直接测量，请明确写出 |
| 分辨率或迁移核 | 公式、参数、响应矩阵；若理想无展宽，请明确写出 |
| 响应核的归一化范围 | 全观测量范围、物理范围或截断范围；若论文规定了边界请给出处 |
| 效率/接受率 | 公式或数据文件；注明作用于真实反冲量、平均观测量还是重建观测量 |
| 阈值、分析窗口和各探测器差异 | 给每台探测器的参数表；共用模型也请说明 |

| --- | --- |
| 分箱所用的观测量和单位 | 应与第 2 节一致 |

## 7. 统计分析【只在要求 likelihood、χ² 或置信区间时填写】

- [ ] 原始逐箱计数
- [ ] 信号加背景计数
- [ ] ON/OFF 数据
- [ ] 已扣除背景的 excess
- [ ] 非分箱事件

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 观测数据文件及其 bin/探测器对应关系 | 待填 |
| 背景、OFF 数据或背景扣除方法 | 按实际数据模式填写；不适用则注明 |
| likelihood/χ² 公式或论文位置 | 待填 |
| nuisance 参数、先验和相关性 | 统计模型使用时填写 |
| 协方差/相关矩阵 | 仅所选统计模型需要时填写；缺失不能假定单位矩阵 |

## 8. 外部数值基准【要求复现论文或旧程序数值时填写】

| 项目 | 请填写或给出资料位置 |
| --- | --- |
| 参考结果 | 总事例数、逐箱数组、谱点、拟合结果；给文件或论文图表位置 |
| 生成参考结果的输入点 | 模型参数、源和探测器配置、数据版本 |

缺少外部逐箱基准时仍可构造和内部检验前向模型，但不能宣称逐箱复现外部结果。
