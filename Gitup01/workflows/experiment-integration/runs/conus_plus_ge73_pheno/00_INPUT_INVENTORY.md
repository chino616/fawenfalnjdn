### Release Reactor-Flux Boundary

The PDF records a low-end linear extrapolation over `0 <= E_nu < 0.01 MeV`.
That convention belongs to an earlier numerical draft. Because the first two
Kopeikin nodes would produce a negative spectrum in part of the extreme low
energy interval, the release definition uses a nonnegative piecewise spectrum:

```text
E_nu < 0:                 rho(E_nu) = 0
0 <= E_nu < 0.01 MeV:     rho(E_nu) = 0
0.01 <= E_nu < 2 MeV:     rho(E_nu) = c_match * rho_Kop_interp(E_nu)
2 <= E_nu <= 10 MeV:      rho(E_nu) = rho_Mueller(E_nu)
E_nu > 10 MeV:            rho(E_nu) = 0
```

The matching factor `c_match` must be computed from the Kopeikin interpolation
value and Mueller spectrum value at 2 MeV so that the spectrum is continuous at
2 MeV. The normalization integral
`N_rho = integral_0^10MeV rho(E_nu) dE_nu` must be recomputed from this
nonnegative release spectrum. Do not keep a legacy extrapolation mode unless a
future request explicitly asks to reproduce the old draft.

### Chi-Square

- Signal normalization nuisance: `sigma_alpha = 0.169`
- Theory prediction: `R_i^th(C)`
- Chi-square:
  `sum_i [R_i^exp - (1 + alpha) R_i^th(C)]^2 / sigma_i^2 + (alpha / 0.169)^2`
- Analytic profile:
  `alpha_hat = sum_i Delta_i R_i^th / sigma_i^2 / (sum_i (R_i^th)^2 / sigma_i^2 + 1 / 0.169^2)`
- `Delta_i = R_i^exp - R_i^th`
- One-dimensional 90% confidence threshold: `Delta chi^2 = 2.705`
