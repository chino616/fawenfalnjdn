# 旧实现的生成诊断

此处保存用户指定旧目录2026-11-06审计的JSON/CSV、网格数组与代码快照。数据属于项目生成结果，直接来源登记为P00的S_AUDIT、S_AUDIT_CODE和具体代码来源。当前数据来源可逐项读回，原目录的186项测试只表明当时的工程验证范围。

[input_resolution.json](input_resolution.json) 汇总逐箱输入、背景分解、时间注量约定、核资源和两套独立benchmark。各 `RESPONSE_*_bins.csv` 保存预测、观测与residual，`ROOT_*` 保存相关/源表示对照，`signal_grid_cases.npz` 和 `time_fluence_scope_grid.npz` 保存网格前后差。

原诊断使用14.57kg、弱角0.2387、200点谱插值和效率常数项−0.3333。新草稿中的论文质量及官方效率分别为14.6kg和−0.333322，出处由P01逐项标出。本文件中的数值不冒充新配置已运行。BRN/NIN归一及严格原论文模型差异继续按当前P02说明。

`code/` 保留相关算法与直接读取约定。物理参数表、处理步骤和原始数值依赖均追到P00/P01，生成结果与实验测量分别标注。
