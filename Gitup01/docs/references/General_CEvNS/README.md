# General_CEvNS 文献

收录跨实验分析及没有唯一实验归属的通用 EFT/NSI 理论。

分类以本页小标题区分；本目录内全部论文如下。每份 PDF 仅在文献库中保存一次。

## 跨实验 NSI 分析

### Constraints on neutrino non-standard interactions from COHERENT, PandaX-4T and XENONnT

- 作者：Gang Li, Chuan-Qiang Song, Feng-Jie Tang, Jiang-Hao Yu。
- arXiv：[2409.04703v2](https://arxiv.org/abs/2409.04703v2)；归档版本：v2。
- 涉及实验／数据集：COHERENT / CsI、Ar；PandaX-4T、XENONnT。
- 本地文件：[PDF](2409.04703v2.pdf)。

在 EFT 框架下比较 COHERENT 与太阳 8B 测量对 NSI 的约束，考虑散射截面和太阳中微子传播效应；跨实验引用共享同一 PDF。

## 通用 EFT 框架

### Comprehensive Effective Field Theory Framework for Coherent Elastic Neutrino-Nucleus Scattering

- 作者：Gang Li, Chuan-Qiang Song, Feng-Jie Tang, Jiang-Hao Yu。
- arXiv：[2601.19883v2](https://arxiv.org/abs/2601.19883v2)；归档版本：v2。
- 涉及实验／数据集：通用 EFT；COHERENT、CONUS+、PandaX-4T、XENONnT。
- 本地文件：[PDF](2601.19883v2.pdf)。

建立从高能理论、SMEFT、LEFT 到手征与核响应的 CEvNS EFT 框架，讨论至维数 8 的算符、QCD 跑动、匹配及多实验约束。
