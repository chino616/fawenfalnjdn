# COHERENT

COHERENT 利用美国橡树岭国家实验室 SNS 的停止 π 衰变中微子源，以不同靶核研究相干弹性中微子-原子核散射。本目录区分 CsI 首次观测、更新的 CsI 数据和首次液氩测量，不把材料名或论文版本当作数据身份。

| Dataset | 探测器／靶材与身份 | 程序 dataset_id |
|---|---|---|
| [CsI2017](CsI2017/README.md) | CsI[Na]；首次 CEvNS 观测所对应的项目复现数据集 | `CsI2017` |
| [CsI2021](CsI2021/README.md) | CsI[Na]；更新 CsI 数据所对应的项目九箱复现输入 | `CsI2021` |
| [Ar2020](Ar2020/README.md) | CENNS-10 液氩；首次氩测量及其公开数据说明 | `Ar2020` |

三个 dataset_id 均已接入程序；其现有输入的 legacy-derived、DRAFT／人工未审查等限制仍以正式输入说明为准。这里的身份索引不把工程接入等同于官方数据逐项核验。

相关论文集中在 [COHERENT 文献库](../../references/COHERENT/README.md)：[CsI 首次观测](../../references/COHERENT/1708.01294v1.pdf)、[更新 CsI 测量及数据附件](../../references/COHERENT/README.md#csi2021-官方数据附件)、[氩首次测量](../../references/COHERENT/2003.10630v7.pdf)、[氩数据释放](../../references/COHERENT/2006.12659v2.pdf)、[CsI/LAr 联合分析](../../references/COHERENT/2211.11905v2.pdf)。通用 EFT 与跨实验分析见 [General_CEvNS](../../references/General_CEvNS/README.md)。
