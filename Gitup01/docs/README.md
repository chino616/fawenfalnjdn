# 文献与实验数据集资料

本目录只保存论文 PDF、文献索引，以及具体实验和数据集的简短说明。

| 入口 | 内容 |
|---|---|
| [references/](references/README.md) | 19 篇论文，按 COHERENT、CONUS、Solar_CEvNS、General_CEvNS 四个文献集合归档 |
| [experiments/](experiments/README.md) | COHERENT 实验及 CsI2017、CsI2021、Ar2020 三个已接入数据集的身份和代码／数据入口 |

每篇论文只归档一份 PDF；涉及多个实验时使用链接交叉引用。新增论文时同步分类 README、文献总目录和涉及的现有 Dataset README。关联公开数据入口、版本、格式和核验范围也登记在文献 README 中。实验或 Dataset 目录只按实际身份建立，不为每篇论文、版本或论文年份建目录。

数据采集时间、数据释放时间与论文发表时间分别记录，未知项注明“未注明”。这些 README 只提供说明和索引，不注册实验，也不代表数据已通过科学验证。
