# 文献与实验数据集资料

[当前五条实验：最新版本与处理方式](<experiments/LATEST_EXPERIMENTS.md>)。本入口仅列当前选定分析；不同方法的输入、代码、结果和审核范围分别说明。

本目录保存论文PDF、文献索引、实验/dataset说明与onboarding报告；跨实验共同文档由明确命名的联合分析目录管理。

| 入口 | 内容 |
|---|---|
| [references/](references/README.md) | 19 篇论文，按 COHERENT、CONUS、Solar_CEvNS、General_CEvNS 四个文献集合归档 |
| [experiments/](experiments/README.md) | COHERENT、CONUS+、PandaX-4T、XENONnT的实验与dataset文档；[PandaX4T／XENONnT太阳⁸B联合目录](experiments/PandaX4T_XENONnT_SolarB8/README.md)集中保存两实验的合版与共同报告 |

每篇论文只归档一份 PDF；涉及多个实验时使用链接交叉引用。新增论文时同步分类 README、文献总目录和涉及的现有 Dataset README。关联公开数据入口、版本、格式和核验范围也登记在文献 README 中。实验或 Dataset 目录只按实际身份建立，不为每篇论文、版本或论文年份建目录。

数据采集时间、数据释放时间与论文发表时间分别记录，未知项注明“未注明”。这些 README 只提供说明和索引，不注册实验，也不代表数据已通过科学验证。
