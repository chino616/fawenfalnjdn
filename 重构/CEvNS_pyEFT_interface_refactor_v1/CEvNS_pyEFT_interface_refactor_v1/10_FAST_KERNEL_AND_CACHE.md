# Fast 系数核与缓存生命周期

状态：DESIGN。当前实现见 `kernels/builder.py`、`reconstruction.py`、`storage.py`，源码证据见 [01](01_BASELINE_AUDIT.md)。

## 1. 先声明数学能力

当前 Fast 建立在固定模型下对 Wilson 系数双线性响应的表示上。典型形式：

\[
N_b=\operatorname{Re}\sum_{s,I,J}H_{s,b,IJ}\,
\operatorname{Tr}(\rho_s C_I^\dagger C_J).
\]

该式要求所采用的 rho 可从源能量积分中按该形式提出，并要求被扫描参数的依赖确实由这些系数描述。
能量依赖 rho 不能一般性放到积分外；传播与扫描参数相关时，总预测也不一定仍是这种固定二次形式。
只有模型声明并验证系数表示、状态条件和固定参数范围，才允许此编译器使用。

`InteractionModel.dsigma_dT` 是必要但不充分条件。不能用 bool 字段 `supports_fast=True` 代替系数表示和等价性证明。

## 2. Fast 应消费与 Slow 相同的模型

建议新增明确编译入口：

```python
# DESIGN
compiled = compile_fast(model, numerics=settings, compiler=compiler)
prediction = compiled.predict(parameters=point)
```

编译器读取已经解析的 source、targets、observation、binning 和理论模型约定。
不在 builder 内重选 SNS loader、Cs/I 权重、接受率或 PE bins。
Fast 与 Slow 可以采用不同计算表示，但必须共享实际物理输入的归属和版本。

当前 builder 独立展开 R 通道公式。重构选择一种可审查策略：

1. 将双线性系数构造放入唯一理论 owner，由 Slow/Fast 的不同收缩表示共同使用；或
2. 保留两种数学实现，但有逐点、逐通道、复系数的独立等价测试，并明确维护责任。

优先减少重复；不为追求“唯一函数”牺牲物理可读性或把数值差异隐藏起来。禁止继续增加第三份拷贝。

## 3. 模板轴

新模板显式保存 target/source/channel/operator_i/operator_j/observable axes。
一维和二维的物理轴分别记录；不能只给旧 6D full_kernel reshape 就宣称支持时间。
旧 storage 校验假定 6D 与 pe_bins，必须在新模板 schema 中扩展或使用有映射的展平观测轴。
新 schema 使用独立标识（建议 `interface_kernel_v1`），已有 `flavor_schema_version=1` 保留其原含义，不能借它表示所有接口都已升级。

复数 pair 模板的符号约定需要冻结。当前 pair_im 存储与 Im 双线性组合的符号必须联合核对，不单独“纠正”其中一项。
通道数、算符基底顺序、sector 不干涉规则、目标与源顺序均为合同的一部分。

## 4. 指纹应来自真实依赖

`CompiledKernelRecord` 至少记录：

- 物理过程、核响应/匹配/运动学约定；
- operator basis、顺序、系数维数与缩放；
- 实际固定的理论参数；
- 核素、质量约定、组成/核数（仅当已编入核）；
- 源连续谱/谱线内容、支撑、插值、归一化与运行期；
- 相关入射态是否已编入核及其参数依赖；
- 已折叠的响应、效率、选择和时间模板；
- 观测轴边界、单位与展平规则；
- 求积网格和数值策略；
- 相关实现版本/内容指纹与数据内容哈希。

生成指纹时使用稳定序列化：字典键排序，数组含 shape/dtype/规范化数值字节或稳定数值表示，模型版本与资源 SHA256 明确。
不得用对象 repr、内存地址、文件路径或整个工作区的修改时间代替内容。
仅 git 提交也不足以识别外部数据内容和工作区未提交实现。

扫描的 Wilson 值若没有编入 H，就不应成为 H 的缓存键；它们必须进入 Prediction 运行记录。
固定 rho 若在重建阶段外置，则记录核的状态能力及其数学要求，rho 的具体值进入重建记录；若已积分进 H 则属于核指纹。
sin²thetaW 若通过 SM 系数在重建阶段注入，也不应误列为只要改变就必须重建的固定 H 输入。

## 5. 失效矩阵

| 改动 | 可以保留的对象（条件满足时） | 需失效或更新 |
|---|---|---|
| 只改受支持的 Wilson 扫描值 | H、源和探测器数据 | 最终预测/统计 |
| 改源谱或谱线 | 裸核响应、同一网格上的纯探测器概率 | 源积分结果、含源的 H |
| 改质量/曝光归一化 | 单核响应、纯探测器概率 | 已包含这些因子的 H/预测；可验证的纯比例更新需新记录 |
| 改核响应/LEC/运动学 | 源和独立探测器模型 | 裸相互作用系数及所有依赖它的 H |
| 改展宽/效率/选择 | 每核反冲产额、裸相互作用核 | 观测折叠及含它的 H |
| 改 binning | 未分箱的中间谱（若有） | 入箱概率、H、统计轴映射 |
| 改统计观测/背景 | 物理预测和 H | likelihood/profile |
| 改数值网格 | 不依赖该网格的物理模型 | 网格数组及相关数值结果 |

失效范围由实际模型依赖记录推导，不要求所有修改都删除所有缓存。
`STALE` 是结果状态，不冒充现有 workflow Machine/Human Gate 的枚举。

## 6. 旧核的处理

现有模板仍可经明确的 legacy 重建入口使用，保持原行为。
新组合模型请求复用旧核时，若缺少必要物理依赖指纹，拒绝自动兼容。可以重建，或在明确审核的迁移工具中生成真实记录；不得在加载时填默认值让校验通过。
读取成功、数组 shape 一致与物理兼容是三项不同检查。

## 7. 必需验证

对所支持的模型，验证多个 SM/NP、复系数、多味点下的每源、每靶、逐箱结果；低层单通道可以为带符号贡献，不要求每块单独非负。
full 与 diag/pair 重建等价；文件保存/加载前后结果一致。
更改效率数表内容但保持文件路径相同，必须使受影响的核失效。
改变统计数据不能使纯物理核无故失效。
不支持的 rho(E)、参数依赖或新过程在构建前报告具体能力缺口。

本轮验证现有模型的一维 Fast、模块替换和实际依赖失效；接口审阅见 09。
