# 分阶段执行计划 R0–R6

状态：DESIGN。R 编号表示本包工程工作包，不等于项目 P01–P10 物理阶段。
初始推荐交付范围为 **R0–R3**；R4 为 Fast 完整迁移，R5 为模块接口审阅与替换验证，R6 汇总实际支持能力。
每阶段是否继续由用户实际授权和适用规则决定，不由本包虚构新的批准门槛。

## R0 — 基线与可重复执行环境

**输入**：实际仓库、当前提交、适用 AGENTS、已有测试和本包。

动作：

1. 确认源码差异和 dirty files，建立逐文件变更计划。
2. 检查 Python、NumPy、SciPy、pytest 是否可用；按环境许可建立可复现测试环境。缺依赖如实说明，不记录测试 PASS。
3. 冻结当前 CsI2021：SM、允许的单算符 NP、SM+NP、复系数、多味矩阵点的逐源/逐靶/逐箱结果与参数。
4. 核对当前 active operator registry 再选择有效矩阵点；不臆造支持的 LNV 对角输入。
5. 冻结 CsI2017 和 Ar2020 的必要计数回归；现有测试不足时增加有意义的基线，不从 backup 自动取参考。
6. 检查当前 Fast：如尚无可用模板，按当前源码在小基底生成诊断，再决定完整测试成本。不存在的结果记 NOT_RUN。
7. 同时记录 source、核响应、选择、数值网格和代码/数据哈希。

**产物**：基线报告、测试日志、参考数据及 metadata、变更路径清单、当前能力表。
报告/参考文件保存到已授权的测试或报告位置，不污染实际实验数据。

**通过条件**：能在修改前重现基准；现有已知失败与环境问题明确分离。
**禁止**：把总数匹配当作逐箱匹配；为修复环境顺便修改物理实现。

## R1 — 合同与旧实现适配

**输入**：R0 基线与已明确的 03–05 合同。

动作：

1. 建立 Source/Run/Target/Interaction/Observation/Prediction 的最小合同。
2. 建立坐标、单位、归一化、有限值和能力检查。
3. 包装 SNS、Li2026、CsI 响应；显式构造核数。
4. 参数若未被旧实现消费，补齐实际传递或拒绝该参数，不建立无效配置项。
5. 保留旧 import 和调用入口，避免大范围移动文件。

**产物**：可实例化并可独立求值的适配器、合同测试、模块描述初版。
**通过条件**：源/截面/响应适配逐点等于旧实现；不同实例不互相污染；错误单位/曝光组合被拒绝。
**禁止**：把只有 Protocol 声明而没有调用方的工作报告为模块化完成。

## R2 — 通用 Slow 一维链

**输入**：R1 适配器；明确 `legacy_csi2021_v1` 数值策略。

动作：

1. 从原嵌套计算抽出每核反冲产额 RecoilYield。
2. 通用能量积分处理任意组件名、空/多谱线和源支撑；在实际能量子网格查询状态。
3. 折叠层保留旧 PE 网格、插值、效率和非负截断顺序。
4. 靶核数在明确位置乘一次，保存实际物理分量和选择前诊断。
5. 不使用源对象中的 detectorMassKg，不在通用层引用 SNS 端点。
6. 在两个以上网格设置比较新旧，不把仅粗网格 smoke 当完成。

**产物**：独立新 predict 路径，带轴 Prediction，逐箱新旧差异报告。
**通过条件**：完整指定参数集回归满足冻结标准；源强/质量线性、谱线、分量求和测试通过。
**禁止**：为了通过结果添加未解释的全局归一化修正。

## R3 — 组装入口、兼容 API 与替换演示

**输入**：R2 回归通过。

动作：

1. 实现 make_csi2021_model；统一解析配置与实际参数记录。
2. 让旧 slow_counts_csi2021 在验证后委托新路径并返回原语义。
3. 统计一维适配使用同一预测，验证旧近似 chi² 没有因单位误读改变。
4. 以一个等价源 adapter、一个明确的源强缩放实例演示 source 插槽替换；再用 identity/zero efficiency 等验证 observation 插槽。
5. 同一进程交替运行两个模型，证明无全局变量污染。
6. 提供实际依赖图、ModuleDescriptor 与兼容性检查结果；Skill 可以读到这些信息。

**通过条件**：仅增加实现并改组装选择即可完成同合同替换；旧入口保护通过；新通用模块不 import 具体实验；未消费配置报错。
**首个可交付成果**：CsI2021 9 箱接口重构完成。此时不宣称新实验、时间或一般 Fast 已完成。

## R4 — Fast 与缓存接入同一物理模型

**输入**：R3；当前 Fast 公式和复系数重建已有可检查基线。

动作：

1. 实现独立 Fast capability 检查，只接受数学结构受支持的模型。
2. 源、靶、观测、选择、数值设置来自解析后的模型；移除共用 builder 的实验选择。
3. 为 Slow/Fast 的系数响应关系建立明确唯一公式归属或可验证的生成/等价机制，不继续复制第三套公式。
4. 新模板保存物理依赖指纹；新模型不自动复用缺少指纹的旧模板。
5. 覆盖 full 与 pair 重建、复相位、源分量、核素和逐箱比较。

**通过条件**：在声明能力范围内 Slow/Fast 逐箱一致；改变一项依赖时拒用过时核；扫描量与预积分依赖区分正确。
**受阻时**：保留已验证 Slow，Fast 能力表如实标记；不得降精度或换物理来强行支持。

## R5 — 模块接口审阅与替换验证

**输入**：R3、R4 和实际模块描述。

动作：核对公共 API、单位/轴、配置消费和依赖图；通过真实 predict 入口演示源与效率替换，验证双实例隔离；确认失效边界及错误能力报告。具体审阅见 09。

**产物**：实际能力表、替换卡、公共接口示例及剩余限制。

**通过条件**：只改组装实例即可完成同合同替换，不依赖实验名字或全局 monkeypatch；保持现有物理结果和旧入口。

## R6 — 发行验证与 Skill 使用说明

**输入**：R3–R5 的实际实现和验证记录。

动作：

1. 清点所有公共 API 的调用与兼容性。
2. 运行必要测试、安装/import 和非项目 cwd 下的资源读取验证。
3. 更新实际能力矩阵、模块描述导出和可读例子。
4. 按 12 的协议完成一次真实可审阅的替换演练；如用户另行要求更新现有 Skill，按其安装/同步规则处理。本包本身不安装 Skill。
5. 汇总剩余物理审计与未接入能力，保留诚实的完成状态。

**通过条件**：文档描述与实际执行一致；既有 CsI2017/CsI2021/Ar2020 回归没有退化；没有误称官方二维 likelihood 完成。

## 阶段记录与恢复

每个阶段保存 commit、输入资源哈希、参数、实际测试命令/结果和下一动作。
恢复时先核对这些记录与代码是否一致；未通过的检查保持 FAILED/NOT_RUN，不根据文字“上次差不多完成”继续。
不以删除旧实现为阶段完成的必要条件；兼容层可以在明确生命周期下保留。
