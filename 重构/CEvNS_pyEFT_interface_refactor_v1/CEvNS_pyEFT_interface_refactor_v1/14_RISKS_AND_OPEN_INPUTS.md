# 资料缺口、物理限制与范围控制

状态：CURRENT 事实 + DESIGN 处理边界。与 [01](01_BASELINE_AUDIT.md) 的源码依据联读。

## 1. 工程上已经选定的方向

以下是本包建议采用的工程路线，不需要执行者重新猜测：

- 先重构 CsI2021 一维旧行为，再处理新物理能力。
- 外层 MeV/keV，理论内层保留现有 GeV 约定。
- 计数器消费运行期积分注量和明确核数。
- Source/Target/Interaction/Observation 由实验工厂显式组装。
- 保留旧 API，以独立新链通过回归后再委托。
- Skill 用真实模型描述和依赖记录决定替换范围。

这些决定不批准未知数据的物理解释，不替代当前仓库的适用流程。

## 3. 既有行为需要保留但不提升为普遍物理结论

SNS tabulation、节点 mask 和积分端点分别记录；不把旧尾部处理写成唯一正确物理谱。
当前核质量 A×amu、CsI 材料质量权重和 CsI2017 14.6 归一化属于具体复现约定。
当前 nu/antinu 标签独立于 flavor，但标签本身不改变互动核的所有符号/螺旋度处理。
当前统计数据有 legacy approximate 标识；接口升级不改变这一事实。
当前 Fast 已有格式/schema 校验，但不是完整物理内容兼容校验。

## 4. 防止范围失控

本包不要求一次覆盖太阳源、反应堆、多个探测器、任意联合响应及新末态。
这些场景用于检验边界是否合理，不代表当前实现任务已经包含所有实验迁移。
不为未来每个可能变量创建一个抽象类；先让首条真实链和有限替换例子闭合。
不把接口重构与微服务、动态插件平台、UI 重写或仓库整体重排绑定。
不把文档完整度、测试通过率和物理审核完成度混成一个数字评分。

## 5. 资料请求应具体

只为本轮模块化与接口工作询问必要输入，不将未请求的物理扩展变成资料待办。
已有参数、资料和有效授权不重复索取。可从实际可访问来源核实的内容先核实。
不从其他会话或未授权文件中自动补资料；源码、公开来源与用户本次选择的材料分别记录来源。
