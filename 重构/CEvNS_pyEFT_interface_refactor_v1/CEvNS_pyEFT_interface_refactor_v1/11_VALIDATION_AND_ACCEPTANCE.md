# 验证、验收与科学结论边界

状态：DESIGN。本文件定义后续实施要执行的检查，不是已通过测试清单。
当前已有测试见 01；阶段通过条件见 08。

## 1. 验证分层

| 层级 | 核验对象 | 不能据此声称 |
|---|---|---|
| 合同 | 单位、轴、有限值、归一化类型、能力 | 某篇论文的物理实现正确 |
| 适配 | 同样输入映射到旧实现得到同样输出 | 旧实现没有物理问题 |
| 整链回归 | 原有逐箱行为未改变 | 新模型也应等于旧模型 |
| 不变量/解析极限 | 核数、线性缩放、运动学、概率、求和闭合 | 所有外部数据语义都正确 |
| 独立物理基准 | 解析结果或有来源的独立计算/数据 | 超出该适用域的模型都正确 |
| 数值收敛 | 网格加密/算法误差可控 | 统计模型等同官方 likelihood |

## 3. 关键用例

### V01：旧结果逐箱复现

R0 参考来自变更前的实际代码，附运行参数、输入内容哈希、版本和生成命令。
SM、受支持的单算符、SM+NP、复系数、多味输入均有代表点。基底/sector 合法性从当前 operator registry 确认。
比较总数之外的每源和实际靶贡献；兼容 raw 用其历史归一化单独比较。

### V02：归一化责任

固定模型形状，源强翻倍，各相关箱翻倍；仅质量翻倍，单核反冲产额不变，最终事件翻倍。
每秒通量×活时间与相同积分注量输入一致；已经积分的注量不能再乘活时间。
接受率为零/一的极限，以及含选择模板的防重复检查。

### V03：源替换确实经过同一主链

采用任意非 legacy 组件名、不同能量支撑、无谱线/多谱线的简单源；用可解析的玩具截面或独立积分作为测试基准。
玩具数据只用于算法测试，明确标 test fixture，不写成真实实验输入。
不得通过 monkeypatch 全局 SNS loader 完成此用例。

### V04：状态坐标

两个长度相同但能量不同的网格应得到对应状态，错误拼接被拒绝。
连续谱支撑掩码后的子网格与单线能量均正确查询状态。
常量态路径与显式重复态一致；能量依赖态应有独立收缩参考。

### V05：探测器与分箱

真实入箱概率非负且对互斥箱求和不超过 1（容差内）；全域响应归一与分析窗口接受率分开。
同一模型合并相邻箱应等于原箱求和；有限网格比较采用已说明的数值误差。
events/bin 到 counts/PE 的转换只除箱宽一次。

### V06：可读输出与统计桥

各源/靶贡献之和等于 total；轴顺序与 shape 一致。
一维旧 chi² 用同一输入复现；二维向量的展平与逆映射正确，预测/观测/背景/协方差同序。
不同观测轴、counts/PE 与原始 counts 等不兼容组合必须拒绝。

### V07：新旧实例隔离

构造 A、B 两个模型，按 A→B→A 顺序计算；两次 A 一致，且实例参数互不修改。
缓存键不同的输入不会互相覆盖；修改未列入模型的外部全局不应隐式改变结果。

### V08：Fast 与依赖失效

支持范围内 Fast/Slow 逐箱一致、full/pair 一致、保存加载一致。
同一路径数据内容改变能被识别；仅统计数据改变保留物理核。
显式 Fast 对不支持输入抛出具体错误，不静默回退。

## 4. 容差策略

在 R0 冻结标准，不在看到新旧差异后反向放宽。
计数比较使用 `abs(new-ref) <= atol_events + rtol*abs(ref)`，记录最大差异、最差 bin、源和靶；接近零的 bin 主要看绝对误差。
同离散算法重构的初始建议为 `rtol=1e-10, atol_events=1e-12`，这只是工程候选值：需根据基线精度、求和顺序和数据量说明是否合理。超出时先解释原因，不自动上调。
截面数量级极小，不能照搬 events 的 atol；依据截面自然尺度定义容差。不能用 `atol=1e-12 cm²/keV` 让所有物理截面都轻易通过。
科学收敛容差按分析需要另行定义，并报告网格加密时逐箱变化；不由接口回归阈值替代。

## 5. 测试执行

在实际项目根目录、已准备的环境中执行当前 tests，例如：

```bash
python -m pytest -q tests
```

新增检查按阶段选择；共享核心或公共计数改变后，必须覆盖三个现有 COHERENT 数据集。
环境缺 pytest 或必要依赖时报告 ENVIRONMENT_BLOCKED，不把“无法运行”记成 PASS。
当前生成文档的环境确实缺 pytest；后续执行者应解决运行环境后再进行实现验收。

## 6. 回归参考与独立真值

已有 reference 数组保持不变；新增 baseline 写入独立位置并记录来源。禁止自动把当前输出覆盖参考后再运行测试。
测试旧包装器与新入口若最终都调用新核心，只能证明包装一致，不能证明原行为保持。至少保留变更前基准或独立旧环境。
新模型与旧模型本来可能不同，替换正确应通过合同和新模型独立基准验证，不能要求它们相等。

## 7. 验收报告最低内容

测试名/命令、输入参数、实际 commit、数据哈希、状态、最差误差、支持域、未运行项及原因。
状态使用 PASS/FAIL/NOT_RUN/ENVIRONMENT_BLOCKED 作为工程报告字段，不擅自写入项目 Physics Gate。
只要必要检查未执行，就不能称该阶段已验证完成；允许报告代码实现完成但验证受阻。
